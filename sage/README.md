SNOVA in SageMath
=============

This directory contains a sage script `snova.sage` implementing SNOVA. It generates correct KAT files. The scripts supports the SNOVA variant with rectangular signatures.

In addition an `mayo_snova.sage` script is provided that uses an alternative representation of the SNOVA public map. This version can create valid Round 2 SNOVA KAT files as well as the Round 2 MAYO-1 KAT files. This script demonstrates that MAYO can be considered as an instance of SNOVA with $l=1$.
